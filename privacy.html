Privacy Policy — Shorts Factory

Last updated: 26 November 2026

Shorts Factory is a personal tool run by its owner on their own computer. It is used only with the owner's own accounts. This policy explains what Google user data it accesses and what it does with it.

Data the app accesses

  • YouTube upload access (YouTube Data API): to upload videos the owner has approved to the owner's own channel and to set their title, description, privacy and scheduled publish time.
  • YouTube read access (YouTube Data API / YouTube Analytics): to read basic information about the owner's channel and the view, like and watch statistics of videos the app uploaded.

How the data is used and stored

  • Data is used only to publish the owner's approved videos and to show the owner how those videos perform.
  • The OAuth token and statistics are stored only on the owner's own computer, in an encrypted local store. No server operated by the app receives them.
  • The data is not sold, shared with third parties, used for advertising, or used to train AI models.

Google API Services User Data Policy

Shorts Factory's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access and data

Access can be revoked at any time from your Google Account's Third-party apps & services page. Deleting the app's local data folder removes everything it stored.

Contact

Questions about this policy can be raised on the project's GitHub page.
